# core 與資料：v8 新增 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 core 回答 v8 網站需要的每個問題：指定平台／卡數／人數的效能與所有切法、卡數範圍的速度曲線、自訂硬體、匯入的模型、人數漏斗；資料端補上自訂硬體範本、漏斗預設值、瀏覽器可用的 HF 抓取與準確度摘要。

**Architecture:** 新的公開函式放在 `packages/core/src/performance.ts` 與 `packages/core/src/funnel.ts`，重用 `api.ts` 內部的 `prepare`、`ctxForPlatform`、`verifyFor` 等（改成具名匯出、不經 `index.ts` 公開）。自訂硬體在 `resolvePlatform` 旁新增 `resolveCustomPlatform`，產生同樣形狀的結果，所以所有後續程式不分目錄平台或自訂平台。資料端新增兩份設定與 schema，validator 檢查參照。

**Tech Stack:** TypeScript 7、zod 4.6.5、Vitest 5（沿用 repo 版本，不新增套件）。

**Spec:** `docs/superpowers/specs/2026-10-21-direct-manipulation-design.md`（下稱「設計」）第 5、6 節；主設計 `docs/superpowers/specs/2026-10-19-inference-calculator-design.md`（§2.1、§4.3、§5）。

## Global Constraints

- 資料誠信（主設計 §2.1）：core 不寫死任何硬體、模型、工作或校正數值；新數值只進 `config/`，每個都有 `status`／`source`／`verified`，`estimate` 附 rationale 與 evidence。
- 錯誤契約不變：使用者輸入問題丟 `CoreInputError`（`invalid-input` | `unknown-id`）；規模、上下文、TP 問題用 `ok: false` + `why` 回傳。
- 一個公式只有一份（Ruling R31c）：新函式只能組合 `checkShape`、`shapeUsage`、`shapeProfile`、`maxConcurrent`、`legalTpOptions`、`verifyFor`，不複製它們的算式。
- core 保持純函式，不用 Node 或 DOM API。
- 每個結果附 `basis`、`hasEstimate`、`hasUser`、`warnings`、`dataVersion`，規則同 `estimateRequirements`。
- 程式註解與 commit 用英文（conventional commit），設定檔註解與 rationale 用繁體中文。
- `config/models/*.yaml` 不可手改。

## Review Focus

1. `gpus` 小於最小合法 TP（例如 GPU 平台 TP 都要 2 而 gpus = 1）→ `splits` 為空，`ok: false`、`why: 'tp'`、`usage: null`，不丟錯（Task 1 測試 `no split fits in the GPUs given`）。
2. `gpus` 等於建議值但使用者給了非建議的 `tp` → 結果是那個切法，不是建議值；`recommendedTp` 仍是建議的（Task 1 測試 `tp override keeps recommendedTp`）。
3. 自訂硬體 `unit: 'machine'` 卻給 `gpusPerNode > 1` → `CoreInputError('invalid-input')`（Task 3 測試）。
4. `gpusList` 未排序或有重複 → `CoreInputError('invalid-input')`，不默默排序（Task 2 測試）。
5. 匯入的模型欄位 `source` 和傳入的 `source.id` 不一致 → `CoreInputError('invalid-input')`（Task 4 測試）。
