# Comparison charts (website v9) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the pinned-snapshot comparison table with live comparison lines (one-click per platform row, "換一項比較" variants) shown as a summary plus overlaid users→speed, users→TTFT and GPUs→speed charts.

**Architecture:** State keeps `compare: CompareLine[]` (only the fields a line overrides); `compute/compare.ts` turns each line into a core `estimatePerformance` / `estimatePerformanceSweep` query (core gets an optional `curveUsers` so every line is sampled at the same log-spaced user counts); `CompareCard` renders the summary (antd Table / narrow cards) and `CompareChart` (D3 on the shared `chart-draw` helpers) draws the overlaid lines with a shared hover crosshair.

**Tech Stack:** TypeScript 7, React 19, antd 6, d3-scale/d3-selection/d3-transition, zod (core), Vitest 5 (+jsdom), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-22-compare-v9-design.md` (visual spec `docs/prototypes/calculator-demo-v9.html`). Read both before any task.

## Global Constraints

- Web code never implements a formula: every number comes from `@nchc/core` (CLAUDE.md "One formula, no copies").
- UI only from antd; icons only from `@ant-design/icons` (no emoji / glyphs).
- Motion token 400 ms ease-out cubic (`transitionMs()`, `easeCubicOut`, `moving`, `keyed`, `translate` from `chart-draw.ts`); `prefers-reduced-motion` → 0 ms; nothing pops.
- No horizontal page scroll at 390 / 768 / 1024 / 1440 px, light and dark.
- Every user-visible string in both `packages/web/src/i18n/zh-TW.ts` and `en.ts`.
- Max 5 lines (`COMPARE_MAX = 5`); colours by slot (never by rank):
  light `#2a78d6 #eb6834 #1baf7a #eda100 #e87ba4`, dark `#3987e5 #d95926 #199e70 #c98500 #d55181`; letters `A B C D E`.
- Estimate lines (`perf.hasEstimate`) dashed `6 4`; read lengths offered: 8000 / 32000 / 128000 tokens.
- Commit messages: conventional commits in English, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- After `config/` or core changes run `pnpm data:build && pnpm calibrate` before web tests (plain `pnpm test` does it).

## Review Focus

- A line whose quant is not offered by its model after the sentence's model changes → falls back to that model's first quant, never a thrown error (Task 4 test `quant falls back when the line's model does not offer it`).
- A line pointing at a custom platform that is deleted (and the undo restore) → the line is dropped / others re-keyed, never `unknown row` thrown (Task 2 tests).
- Core rejecting a line's query (`CoreInputError`, e.g. 128k read length over the model's max context) → the line shows 放不下 with core's message, the rest of the card renders (Task 4 test `a CoreInputError becomes an error line`).
- A shared URL with a malformed / oversized `cmp=` → ignored entry by entry, never breaks the page (Task 3 tests).
- All lines unable to fit (no curves) or a single machine-only line → charts render empty with the "放不下" note, hardware chart hidden, no NaN in paths (Task 5/6 tests).
